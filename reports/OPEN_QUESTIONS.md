# Closed experiments and open questions

This file records the existing stopped routes and questions that remain unanswered. It proposes no authorized experiment and introduces no new result. The three commercial character models and all derived assets are excluded; Char-A / Char-B / Char-C are anonymous labels. **USER_VISUAL_ACCEPTANCE = PENDING.** See [SOURCES.md](SOURCES.md) for original report filenames and section references.

## Routes closed in the existing bounded research

| Route | Existing result and reason to stop | Source |
|---|---|---|
| Residual meshlet | One fixed Char-A eyeline ADD_ONLY engineering candidate restored `19/19` union pixels, but the two LOCAL_REPLACE shoe candidates added `+2` and `+1` aspect>100 triangles and did not pass the no-regression requirement. Full transition compression ratios were `0.2×` and `0.2857×` for the two shoe cases. The reported route was `HYBRID_RESIDUAL_FEASIBLE = PARTIAL`, `REPRESENTATION_EFFICIENCY = POOR`, next step `STOP`. This does not prove all source-supervised meshlets impossible. | **R8G8, `必答結果`, shoe/topology sections** |
| HYBRID_tau2 / raw MeshUDF extraction | Char-A FACE same-depth coverage was V2 `95.82%` versus hybrid `67.26%`; Char-B SHOE was `90.63%` versus `31.48%`; Char-C SHOE was `89.71%` versus `52.56%`. The continuous point oracle was `54/54`, while the hybrid mesh restored `0/54` fixed witnesses. Finite open-sheet synthetic extraction also failed. The particular extractor route was not recommended; the entire hybrid representation family was not disproved. | **R9A, `完整固定 ROI 的診斷結果` and `最終欄位`; R9A-HYBRID, limitation statement** |
| FlexiCubes as the replacement geometry route | Controls used the same field only on certified closed subcomponents; full open/multilayer ROIs were not treated as global SDFs. On the five closed controls, MC had lower mean distance; FC reduced skinny triangles in two controls but demonstrated no complete-character replacement gain. Example closed FACE mean distances were MC `0.000579154` and FC `0.000670719`. | **R9A, `主要發現`, `同一 field 的提取控制`, `最終欄位`** |
| Vertex-only topology-preserving repair | All three A0/A1/A2 proposals stopped on their first safety check; accepted iteration count was `0`. A0 maximum local edge-length ratio was `1.31036`, exceeding `1.25`. A2 introduced `11` face reversals, `24` >170° shared-edge flips and `54` self-intersection/contact risk pairs. Existing missing eyeline sheet witnesses were not recovered. This is a bounded solver failure, not a proof of a global topology ceiling for every body part. | **RREFINE, main result table: refinement, A0, A2, FACE and feasibility rows** |
| G-series fixed-support predictor, latest LINK02 | Correct counts did not give a legal mesh: `51/20184` pointer errors, `72/5046` sign errors, and `9` unreferenced patches remained after the authorized `2000` updates. The original assembler rejected the payload; continuous geometry and visual delivery were not run. It remained target-latent fixed-support autoencoding, without image conditioning or occupied-cell learning. | **RG3D, `實測比較`, assembler and scope statements** |
| Fully expanded fixed-channel V2 neural interface as specified | The sample envelope's provisional cost was `3,915` output channels. A largest single FP16/BF16 output buffer was `23.984499 GiB`; adding the stated int32 xyz accounting gave `24.021257 GiB` before activations/backward/optimizer state. The report labelled this exact full-once layout `NOT_PRACTICAL_AS_SPECIFIED`; neural input and full encoding remained unresolved. It did not rule out every V2 layout. | **RFIXED, `一頁結論`, A accounting** |

These closed routes should not be silently restarted during release preparation. Historical gates and failed predictions remain failed; no visual success is inferred from a completed audit.

## Open questions, not findings

| Question | Existing evidence boundary | Current answer |
|---|---|---|
| What limits direct B @1536 before any VAE? | The two official B/P3 exports contained `34` and `42` NaN vertex rows. The exact intermediate operation was not isolated; no mesh repair was performed. **R10D-FAIL, opening diagnosis and limitation.** | UNKNOWN; the existing failure cannot be attributed to the VAE. |
| Would decoder-only adaptation reduce character reconstruction loss? | Stage10A array losses exist, but the release contains no updated pretrained VAE or decoder-only adaptation result. The fixed-support G-series work is a different representation/predictor experiment. **R10A, B1–B4 and C; RG3D scope.** | NOT_TESTED; no benefit promised. |
| Would remesh_project=1.0 outperform the measured projection setting? | The registered sweep compared project=0 and project=0.9 with specific face targets/resolutions. **R10D, parameter definitions.** | NOT_TESTED; do not extrapolate from project=0.9. |
| Can orientation-only post-processing preserve the direct mesh's shape and depth? | B BODY failure was `87.529%` oriented versus `2.545%` unoriented; current remesh also changes positions/topology. **R9CR, BODY normal table; R10C, D1 pixel summary.** | NOT_TESTED; unoriented diagnostics are not a winding repair. |
| Can a complete official VAE training step fit the target hardware? | The 1024 zero-update probe failed during an extra `792 MiB` master-gradient finite-QA allocation after official F+B returned. Adam m/v were never allocated. **R10C, D3 exact failure and limitations.** | UNVERIFIED; neither full training feasibility nor inherent F+B OOM is established. |
| Can the V2 representation become a usable three-view character generator? | The fixed-channel interface remains partial; G3D did not learn image conditioning/support. **RFIXED, A unresolved interface; RG3D scope.** | UNVERIFIED; this release is research code and evidence, not that product. |
| Are tangent normal-map discontinuities fixed? | Existing TrueNormal tests measured geometric face normals and winding; they did not test UV/tangent texture seams. **R10C, final limitations; RG3D final scope.** | NOT_TESTED. |

The release contains no authorization to run these questions. Any future experiment requires its own bounded protocol, licensed inputs, numerical gates and user visual acceptance.
